# ML & AI Analytics Service

This service handles:
1. **Business DNA Vector Engine**: 9-dimensional quantitative feature generation with mathematical explainability.
2. **Company Embeddings & Clustering**: Semantic representation of corporate descriptions and industry vectors.
3. **RAG (Retrieval-Augmented Generation)**: Grounded QA engine citing exact regulatory documents.
4. **Fusion Lab Engine**: Combinatorial synergy modeling for multi-company hypothetical analysis.

## Setup
```bash
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
```
